# ShowGather V1.2 Persisted Show Configuration Release Candidate — v0.4.0-rc1

`v0.4.0-rc1` is the local release candidate for ShowGather V1.2. It turns the
database foundation introduced in V1.1 into an operator-facing saved-show
workflow while preserving the media-PTS timing and ordered outbox architecture.

## Highlights

- Create, edit and duplicate productions without changing source code.
- Save reusable show configurations and explicitly copy their current data into
  a production.
- Create, edit, duplicate, reorder, enable and disable persisted rundown cues.
- Build canonical presentation commands through typed Admin controls.
- Start independent live and rehearsal execution sessions from immutable
  rundown snapshots.
- Preserve show definitions, durable presentation snapshots and execution
  recovery across API restart.

## Pilot setup

```bash
cp .env.example .env
pnpm install
pnpm pilot:up
```

Open the Admin at `http://localhost:3002` and the Player at
`http://localhost:3003`.

## Validation

- Clean-clone migration and idempotent-seed audit passed against isolated
  PostgreSQL.
- Seed preserved intentionally edited production and cue data.
- API test suite: 11 passing tests.
- Full workspace production build passed.
- Local workflow validated production creation, configuration copy, rundown
  editing/reordering, disabled cues, immutable active sessions, rehearsal/live
  delivery, API restart recovery and durable late-join snapshot hydration.

## Known limitations

- One API dispatcher per database is supported.
- Local Compose is the tested pilot deployment only.
- Authentication, roles, collaboration, assets, templates, analytics, billing
  and production deployment tooling are intentionally out of scope.
