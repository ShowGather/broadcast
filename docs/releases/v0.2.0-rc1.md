# ShowGather V1 Pilot Release Candidate — v0.2.0-rc1

`v0.2.0-rc1` is a local interactive broadcast pilot release candidate.

## What works

- Live HLS playback with timed metadata scheduled against media PTS.
- Configurable score, lower third, alert, sponsor, ticker, and regional-clear presentation commands.
- Durable revisioned snapshots for late joins and reconnects.
- Live and rehearsal operator paths.
- Focused rundown with idempotent GO and explicit re-run.
- Desktop surround regions, mobile companion panels, and TV profile.
- Pilot startup/runbook, screenshots, and baseline CI.

## Pilot setup

```bash
pnpm install
pnpm pilot:up
```

Open the Admin at `http://localhost:3002` and follow the [Pilot Demonstration Runbook](../Pilot%20Demonstration%20Runbook.md).

## Experimental / V1 validation tooling

- The local Compose stack, stream, timing diagnostics, legacy named cues, and rehearsal SSE path are pilot tooling.
- Safari Technology Preview is the documented browser-validation environment.
- Timed ID3 uses a compact 127-byte TPE1 reference adapter and the packet-preserving TS segmenter.

## Known limitations

- Presentation and rundown state is in memory and does not survive API restart.
- No user accounts, permissions, multi-operator workflow, asset library, or template editor.
- No production hosting, CDN packaging, telemetry, or broad browser-support promise.
